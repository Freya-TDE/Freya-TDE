# Appendix A – Glossary

[Contents](README.md) · back: [16 Known problems and limits](16-problems.md) · next: [Appendix B – Licenses](b-licenses.md)

| Term | Meaning |
|---|---|
| **Backend (UI backend)** | pack that translates forms for a UI toolkit (GTK 4, egui, iced, Slint, Flutter, WebView, freya) |
| **Component** | building block with name, type, properties and events |
| **Widget** | component with a visual extension (placement, children) |
| **Form** | a window of the target program; file `.ftdr` next to the `.rs` |
| **Data module** | form without widgets, service container (e.g. `services`) |
| **Pack** | folder with a `pack.toml`: types, templates, dependencies |
| **Provides / requires** | what a component offers or needs; basis of the checks and the order |
| **Data source** | type that delivers rows (`[component.data]`), e.g. the SQLx `Query` |
| **Handler stub** | empty method in your own code that handles an event |
| **`.gen.rs`** | file generated by Freya TDE, write-protected |
| **`.ptdr` / `.ftdr`** | project and form file (RON) |
| **`state`** | a form's own fields |
| **Anchors** | edges an absolutely placed widget keeps its distance to |
| **Snippet** | saved piece of code with a use line |
| **RUF** | Rust native UI Framework – the IDE's UI framework |
| **RNCL** | Rust native Component Library – RUF's components |
| **CT-E / CT-Editor** | Cargo TOML Editor |
| **freya-tde-db** | database helper (separate process) |
| **DAP / LSP** | Debug Adapter Protocol / Language Server Protocol |
