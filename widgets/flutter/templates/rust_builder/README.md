# rust_builder

Glue that builds the Rust library of this project with `flutter build` and
bundles it into the finished program ([cargokit](https://github.com/irondash/cargokit),
MIT, `cargokit/LICENSE`). Created once by Freya TDE; normally nothing to do here.

*Verbindet `flutter build` mit `cargo`: die Rust-Bibliothek wird gebaut und ins
fertige Programm gepackt. Einmal von Freya TDE angelegt.*
